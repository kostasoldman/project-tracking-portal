# Project Tracking Portal

An interactive concept for a company-wide project tracking portal — built to explore what a lightweight, PM-first alternative to heavier enterprise PPM tools could look like.

 **[View the live demo →](https://kostasoldman.github.io/project-tracking-portal/)**

## What it covers

- **Portfolio Overview** — status, health, budget vs. actual, and completion across every active and closed project
- **Project Record** — a full drill-down record per project: Details, Financials, Staffing, Tasks, Risks & Issues, Project Logs, Reports
- **Change Requests** — a formal approval workflow for completion-date changes, with automatic flagging of projects with recurring delays
- **Lessons Learned** — a PMBOK®-aligned post-production retrospective module, with a Priority Score model and a recommendations-to-action tracker that ties findings back into future projects
- **Timesheet** — a personal weekly forecast/actual cycle (set Monday, confirm Friday) that feeds staffing numbers on each project
- Inline editing with dropdowns for status fields, built to demonstrate the data model rather than wire up a real backend

## Notes

- All data shown is fictional, for demonstration purposes only.
- This is a static front-end concept — there's no backend, so edits made in the browser won't persist after a refresh.
- PMBOK® is a registered mark of the Project Management Institute, Inc.

## Tech

Single self-contained HTML file — no build step, no dependencies beyond Google Fonts.
